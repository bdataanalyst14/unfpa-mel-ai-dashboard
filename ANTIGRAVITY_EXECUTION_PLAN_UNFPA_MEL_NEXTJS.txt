Google Antigravity Execution Plan

PROJECT NAME
unfpa-mel-ai-dashboard

TECH STACK
- Next.js App Router
- TypeScript
- Tailwind CSS
- shadcn/ui
- Recharts
- lucide-react
- date-fns

DEVELOPMENT STRATEGY
Build in controlled milestones. Do not attempt backend, authentication, real data connection, or AI API integration in the first build. The first target is a static but polished prototype using realistic mock data.

MILESTONE 1 — Repository Setup and Design System
Goal:
Create the Next.js project, install dependencies, initialize shadcn/ui, and set up the design foundation.

Tasks:
1. Create Next.js app with TypeScript, Tailwind, App Router, src directory, and @ alias.
2. Initialize shadcn/ui.
3. Install Recharts, lucide-react, date-fns, clsx, and tailwind-merge.
4. Configure global styles.
5. Create UNFPA-style color tokens:
   - Orange accent
   - Blue primary
   - Green on track
   - Amber watch
   - Red off track
   - Grey no data
6. Create base app layout.

Expected output:
- Working Next.js app
- Basic dashboard shell
- Clean visual foundation
