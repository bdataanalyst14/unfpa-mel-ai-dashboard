# MEL Demo Scope And Caveat Note

Date: 2026-06-29

## Scope

The SMT demo is `SMT Demo GO WITH CAVEATS`. The dashboard can demonstrate workflow, visual layout, privacy concepts, and aggregate-reporting direction. It must not be presented as final M&E validation, production readiness, live geography, DP-004 clearance, or live GBV/OCMC activation.

## Page Scope

| Page | Demo status | Caveat |
| --- | --- | --- |
| Executive Overview | Aggregate POC with caveats | Pending E001 freshness, E002 final API/browser QA, and final M&E validation. |
| Indicator Progress | Prototype/mock | Demo sample indicators; pending final M&E validation. |
| Management Decision Centre | Prototype/mock | AI insights and narrative are illustrative, not donor-ready evidence. |
| Activity Detail | Prototype/mock | Synthetic `ACT-2025-*` rows are not official activity registry entries. |
| Activity Progress | Prototype/mock | Demo/sample rows pending activity registry validation. |
| Data Quality & Evidence | Prototype/mock | Demo QA examples pending source and M&E validation. |
| Geographic Coverage | `demo_ready_with_caveats` | Protected map prototype/mock; no live geography claim. |
| GBV/OCMC Summary | Blocked for live | Mock/prototype only; live activation blocked pending privacy sign-off and server-side suppression. |

## Required Presenter Language

Use: `prototype/mock`, `demo_ready_with_caveats`, `pending final M&E validation`, `pending final API/browser QA`.

Avoid: final programme sign-off, live data, live geography, DP-004 ready, production ready, donor-ready narrative, or live GBV/OCMC.
